# Computer Networks Project

[cite_start]This repository contains a C-based Computer Network Project  [cite_start]created for OntarioTech University. 

## Features
* [cite_start]**TCP "Hello" Application:** A concurrent server that accepts multiple client connections and transmits a string[cite: 272, 292].
* [cite_start]**TCP File Download:** An application where a client can request and download a file, with the server transmitting data in 100-byte chunks[cite: 308, 309].
* [cite_start]**UDP Time Service:** An iterative UDP server that provides the current system time to clients[cite: 332, 401].
* [cite_start]**UDP File Download:** A client/server application using Custom Protocol Data Units (PDUs) to transfer files over UDP[cite: 373, 374].
