# Computer Networks Project

This repository contains a C-based Computer Network Project created for OntarioTech University. 

## Features
* **TCP "Hello" Application:** A concurrent server that accepts multiple client connections and transmits a string.
* **TCP File Download:** An application where a client can request and download a file, with the server transmitting data in 100-byte chunks.
* **UDP Time Service:** An iterative UDP server that provides the current system time to clients.
* **UDP File Download:** A client/server application using Custom Protocol Data Units (PDUs) to transfer files over UDP.
